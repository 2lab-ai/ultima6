# 08 — i18n: English / Korean chosen at start, Korean in an archaic register

Status: planned (rev 1, 2026-10-15). User item 2 (`hd-i18n-voice/ssot.md`, verbatim): "처음 시작시에 영어, 한글 고를수 있게 해주고 i18n 구현해줘. 고대 영어틱하게 번역해줘". Research notes stay outside the repo: `~/Games/ultima6/research/2026-10-15/r2-i18n-findings.md`.

Reading of "고대 영어틱하게": the original speaks in a faux-archaic English (thou, thee, art, hast). The Korean translation carries the same feel through archaic Korean speech levels (사극체). Modern Korean endings are not used.

## Measured facts

- **Where game text lives:**
  - the conversation scripts (`converse.a/.b`), text inside bytecode, read by `converse/run.rs:73` `run_text`, `exec.rs:218` `print_op` and `:249` `assign`;
  - `look.lzd` (`state.rs:183`);
  - `book.dat` (`objects/commands/look.rs:106-120`);
  - strings in the `game` executable (`GameImage::cstr`, about 15 loader sites);
  - the `u` program (opening, creation, transfer; its own text engine, `intro/text.rs`);
  - pictures: the main menu, title and intro art are drawn shapes (`intro/mod.rs:252-280`), so their words cannot be substituted.
- **The character path is already `i16`** (`ui/printf.rs:74` `text_out`, `ui/print.rs:72` `put_raw`). It is narrowed to a byte in only two places: `line: [u8; 41]` (`ui/textstate.rs:7,21`) and `draw_char(u8)` (`ui/text.rs:131`). The runic bit is `c |= 0x80` (`print.rs:97`), and `printf` pads by bytes (`printf.rs:234`).
- **Typing is the real blocker.**
  - Keyword lists are matched against the bytes the player types (`converse/run.rs:24,125`).
  - `key_from_dom` rejects non-ASCII (`u6-web/src/lib.rs:121`).
  - `read_line` is a 50-byte buffer (`ui/keyread.rs:158`).
- **Font.** Galmuri7 (OFL-1.1, no Reserved Font Name) has all 11,172 syllables at an 8-px advance with glyphs ≤ 7×7, so one syllable fits one game cell. Galmuri14 fits one 16-px cell at HD 2×.
- **Window geometry.** Message rows are 17 cells (`ui/textstate.rs:124-130`). Korean at one syllable per cell carries more per row than English.

## Rights (fixed)

- Committed:
  - our page UI catalog (en, ko);
  - the register guide and class table;
  - the Korean for mechanics vocabulary (spell, item, object and virtue names, which 01 §Rights allows);
  - the Hangul font blob with its OFL text;
  - the tools.
- Local only, never committed or hosted:
  - the translation pack;
  - the glossary rows for names and places;
  - the translation memory;
  - the speakers file.
- The pack lives in `~/Games/ultima6/i18n/ko/`, with a `.gitignore` entry. A repo test fails if a file with the pack magic `U6LP` is tracked or sits under `site/`.
- The translation tool sends the owner's game text to an LLM through the owner's llmux. It prints a consent line and a payload preview first. The page and the engine never call a model.

## Design

1. **Text path (engine; English stays byte-identical).**
   - Widen `line`, `line_ink` and `transcript_line` to `u16`, and let `draw_char` take `u16`. Codes below 0x100 come from the game's `u6.ch`; codes from 0xAC00 come from the Hangul table, a second page of `BitFont`.
   - A UTF-8 assembler in front of the escape layer, enabled only while a locale layer is active (`TextState.wide`).
   - Guard the runic `|= 0x80` with `c < 0x80`, and make `printf` count cells instead of bytes.
   - A pack-only positional `%1$s`, and a josa resolver `{이/가}` `{은/는}` `{을/를}` `{과/와}` `{(으)로}` that looks at the last drawn syllable (batchim rule) and reads digits as Korean numbers.
   - Plural markers `/` and `\` are dropped in Korean.
   - Roster names stay Latin; the 14-byte save field is unchanged.
2. **Lookup keys.**
   - Converse text is keyed (archive, item, hash64 of the run group). A group is adjacent text runs separated only by non-printing ops, so a whole sentence is translated as one unit. At run time the group's translation is emitted at its first fragment, the remaining fragments print nothing, and the ops in between still run in order.
   - Exe and `u` strings use a content hash at the print boundary (`printf`, `puts`, `put_raw_str`, `intro/text.rs`). Logic never sees translated strings, and strings shorter than 3 bytes are not substituted.
   - `look.lzd` and `book.dat` are replaced whole, inside the pack's own layer; `look.lzd` is re-encoded with the existing `lzw::encode`.
   - A miss falls back to the original English, and a miss counter records the hash only.
3. **Pack.**
   - One file `ko.u6lp` holding:
     - meta: language, tool version, base fingerprint over the source files;
     - the converse map with keyword aliases;
     - the strings map;
     - the replacement `look.lzd` and `book.dat`.
   - The engine mounts it as its own `Files::overlay` layer under `locale/ko/`. It is never merged into the base layer, because `resolve` falls back to bare names and would collide with the originals.
   - A fingerprint mismatch refuses the pack and names the part that differs.
4. **Typing Korean.**
   - A hidden `<input>` on the page receives IME composition; `compositionend` text becomes `Key::Char`.
   - The pack carries a Korean→English keyword alias map, applied before `match_keyword`. The typed word has its trailing particle (조사) stripped, and English keywords keep working.
   - Pack syntax `@{…}` marks a highlight explicitly, because `keyword_end` would otherwise swallow Korean particles.
   - `INPUT_MAX` is measured in characters, not bytes.
5. **Language choice at start (page).**
   - A two-button gate "English / 한국어" sits above the drop area. It defaults from `navigator.language`, is stored in `localStorage`, and `<html lang>` follows it.
   - Switching restarts the game from the kept files.
   - Without a pack, Korean shows the Korean page UI with English game text, plus one line pointing at `tools/i18n`.
   - The pack is dropped once and kept in IndexedDB under `locale:ko`.
   - A native `--locale ko` flag does the same in the native build.
6. **Translation tool (`tools/i18n`, local).**
   - The extractor is shared with 09's NPC catalog: one catalog of runs and groups, two consumers.
   - Pass 0: the LLM proposes a glossary (names by 외래어 표기법, common nouns rendered archaic). The owner reviews it, and it is frozen.
   - Pass A: the speakers file. Each speaker class is inferred from the script header, the look text and the object type, and the owner can override it.
   - Pass B: one script per call (200 units), plus about 25 calls for the other sources. Each call carries the style guide, the speaker's class and register, the glossary slice, the NPC's earlier lines and the script's runs in order.
   - The translator and the reviewer are different engines; for example, a Claude model translates and gpt-6-astra reviews.
   - Mechanical gates check structure only:
     - placeholder multiset equal;
     - every code point is a Hangul syllable or ASCII;
     - label strings fit their cell width;
     - josa markers are well formed;
     - keyword aliases are non-empty.
   - The register gate is a review by the second engine plus a 5% sample checked by the owner.
7. **Register (사극체) guide (committed, `tools/i18n/style-ko.md`).**
   - thou/thee/art/hast choose the speech level and the form of address; they have no word-for-word Korean.
   - The default address to the hero is 그대.
   - The class table maps speakers to endings:
     - royalty: 해라체;
     - nobles and mages: 하오체;
     - scholars and clergy: 하오체 with Sino-Korean diction;
     - guards: a clipped 하오체;
     - merchants: an archaic 합쇼체;
     - commoners: a low 하오체;
     - thieves: 하게체 or 해라체;
     - spirits: 해라체 with archaic forms;
     - gargoyles: one marked register, which the owner approves from samples.
   - One speaker keeps one level throughout. No modern ~요 or ~해 endings. Incantation syllables, runic text and credits are excluded.

## Order

1. Text path with synthetic strings.
2. Locale layer, hooks and pack parser, proven by an identity pack (translation equal to source) built at test time from the owner's files: its receipts must be identical to English.
3. Extractor.
4. Page gate, UI catalog, IME and aliases.
5. Glossary and speakers, then one NPC as a sample for the owner, then the full run.
6. The `u` program's proportional text.
7. Galmuri14 at HD 2× (07).

## Acceptance

1. **No pack.** Every English parity receipt is identical, and the language gate shows. Korean mode shows the Korean page UI.
2. **Identity pack.** Real-data receipts are identical, and the miss counter is 0 on the replayed conversations.
3. **The owner's Korean pack.**
   - A conversation shows archaic Korean in the message window with correct particles.
   - Typing a Korean keyword answers.
   - `look` and books show Korean.
   - The dispatcher reads the frames.
4. **Pack location.** The pack is not in git and not under `site/`, checked by test. The live site fetches no pack.
5. **Gates and live check.** All gates pass; the live check runs in both languages.
