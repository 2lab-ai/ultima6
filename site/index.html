What this version does

      
The game starts as the original does: the opening (Escape skips it), then the menu, where
        C creates a character (or T transfers one from Ultima IV or V) and J journeys onward.

      
Works: walking (arrow keys), passing a turn (space), talking (T), combat (A attacks, B
        begins or breaks off combat), casting spells (C), resting (R), looking, getting,
        dropping, moving and using things (L, G, D, M, U), the inventory panel, the mouse (click
        the map to walk, the command icons, the party list, the inventory and the spellbook),
        saving and restoring the game (Ctrl-S, Ctrl-R), music and sound (Ctrl-Z turns the game's
        sound on and off; the Mute button silences the page). Sound starts once you click or
        press a key on the game screen.

      
Speed: on the game screen - slows the game and = (or +) speeds it up, through 1×,
        1.5×, 2×, 3×, 4×, 6×, 8× and Max, but only while the
        game is not using that key: while you type a line or a name, in the stats and inventory
        panels (where - and + pick the member), in a party list long enough to scroll, and in the
        opening's menu, the key is the game's. The keypad - and + and the Speed buttons always
        change the speed. 1× is the original's pace; above 4× the music fades out.
        “behind” means this computer cannot keep up with the chosen speed.

      
HD (on by default; the HD button switches it): the map, the portraits
        and the panels are shown magnified two or four times with MMPX (Morgan McGuire and Mara
        Gagiu, MIT licence: copyright and permission notice), computed in
        your browser from your own files; text and the pointer stay the original pixels,
        scaled. An HD pack made from your own files with the project's local HD tool can be
        dropped here like the game files: its pictures replace MMPX for the images they were made
        from. It is kept in this browser (“Forget the HD pack” removes it) and never
        sent anywhere; this site hosts none.

      
Voices (off until you press
        Voices): the NPCs say their lines aloud, each in an English voice of its own, generated in this browser by
        the Supertonic-3 model (Supertone Inc., Open RAIL-M licence), on WebGPU where the browser
        offers it, else on the CPU (slower). The model is
        downloaded from this site once (about 400 MB), after you accept its use restrictions;
        what NPCs say never leaves this browser. Voice model terms.
        “Forget voices” removes the model and any voice pack from this browser.

      
NPC bundles: the NPC bundles button makes, in this browser, each
        NPC's name and dialogue from the game files kept here (one bundle per conversation script,
        for a later AI to learn how each NPC speaks), keeps them in this browser and downloads
        them as one JSON file. They are never uploaded; “Forget NPC bundles” removes
        them from this browser.

      
Game strings: the game strings button reads, in this browser,
        the game's own messages from the game file kept here (the command prompts and their
        results, the words of a conversation's frame) and downloads them as one JSON file, for
        tools/i18n to make the Korean pack's game strings. It is never uploaded or kept here.

      
Not yet: a few rare object actions (moving a carried thing to someone else, a staff's or
        wand's spell in combat). Those say
        “Not implemented in this version” or do nothing.

      
A character you create and a save (Ctrl-S) are kept in this browser and the next visit resumes it; “Forget the
        saved game” starts over. “Forget the kept files” removes the game files
        themselves.
